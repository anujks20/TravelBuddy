================================================================================

A. Motion Tracking & Kinematics:
   - 6-Degrees-of-Freedom (6-DOF) continuous motion tracking.
   - 3-Axis Accelerometer sampling at ±2g sensitivity.
   - 3-Axis Gyroscope sampling at ±250°/s sensitivity.
   - Total Acceleration Vector Calculation: $A = \sqrt{a_x^2 + a_y^2 + a_z^2}$.
   - Pitch Angle calculation via trigonometric arctangent filter.
   - Roll Angle calculation via trigonometric arctangent filter.

B. Free-Fall & Violent Impact Anomaly Detection:
   - Free-fall Phase Detection ($A < 0.35g$ sustained for $\ge 150\text{ms}$).
   - High-G Crash & Impact Detection ($A > 2.80g$ sudden spike).

   - Automatic `is_fall_detected = true` flag generation.

C. Edge Alarm & Telemetry Communication:
   - Automated Periodic Wi-Fi HTTP POST Telemetry transmission to `/api/iot/telemetry`.
   - Onboard Piezo Buzzer Warning Siren: Emits 2.4kHz audible alarm if backend returns geofence breach.
   - Battery Level Monitoring via ADC voltage divider.
